A deterministic program that writes one museum placard line (149 characters) for an office microwave oven recast as an ancient ritual artifact — daily offerings of fish burned within, that the tribe might endure the afternoon — for make.fun's Office Artifacts: The One-Line Placard Contest.

## Run it

```sh
python3 main.py
```

The program writes the placard to `/output/entry.txt`. No network, no randomness, no clock: two runs produce byte-identical output.
